# PRIVATE MODULE K-12

SF の個室を主観視点で歩けるブラウザ用の試作です。モデル、テクスチャ、照明、音はすべてコードで生成しています（画像・音声ファイルなし）。ゲームとしての目的はまだありません。

## 操作

| | PC | スマホ |
|---|---|---|
| 移動 | W A S D（Shift で早歩き） | 画面の左半分をドラッグ |
| 視点 | マウス | 画面の右半分をドラッグ |
| 操作 | E または左クリック | ACT ボタン |
| メニュー | Esc | 右上のボタン |
| fps 表示 | F3 | ― |

- 扉は近づくと開きます。
- 端末で照明を切り替えられます（AMBER / GLACIER / NIGHT）。
- 中央の卓で投影を切り替えられます（PLANET / TERRAIN / GALAXY / OFF）。
- 洗浄ポッドでシャワーを出せます。
- メニューで、画質、全画面、見た目の切り替え、音の入切、BGM と SE の音量を変えられます。音量はブラウザに保存されます。

## 画質

| | 軽量 | 標準 | 高 |
|---|---|---|---|
| 初期値 | スマホ | PC | ― |
| 輪郭の処理 | なし | FXAA | マルチサンプル4倍 |
| アンビエントオクルージョン（半解像度の GTAO） | なし | あり | あり |
| 窓の外光の影 | なし | あり | あり |
| ブルームの横筋 | なし | あり | あり |
| 描く画素数の上限 | 約160万 | 約210万 | 約240万 |

- fps が 50 を下回る状態が続くと、描く解像度を自動で段階的に下げます（下限は半分）。余裕が続けば一度だけ1段戻します。
- メニューの GRADE（照明モードごとの色調）、SHAFT（窓からの光の筋）、STREAK（ブルームの横筋）は、個別に入切できます。

## 構成

ビルドなしで、リポジトリ直下をそのまま配信します。

```
index.html        画面とメニュー
js/game.js        部屋、照明、映りこみ、後処理、移動、当たり判定、操作
js/audio.js       音（Web Audio の合成）
lib/              three.js r170 と後処理・形状のモジュール（同梱）
```

## 確認用の機能

- F3 キー、または URL の末尾に `#debug` を付けると、左下に fps（実時間）、位置、向き、画質、描画解像度、自動調整の倍率、AO の入切、描画回数、三角形の数が出ます。
- ブラウザのコンソールから `window.ROOM` を使えます。
  - `ROOM.pose(x, z, yaw, pitch)` 位置と向きを指定
  - `ROOM.mood(0〜2)` 照明　`ROOM.holo(0〜3)` 投影　`ROOM.shower(true/false)` シャワー
  - `ROOM.quality('low' | 'mid' | 'high')` 画質　`ROOM.state` 現在の状態
  - `ROOM.grade(0/1)` 色調　`ROOM.shafts(0/1)` 光の筋　`ROOM.streak(0/1)` 横筋
  - `ROOM.ao(4)` AO だけを表示（`ROOM.ao(0)` で戻す）
  - `ROOM.cfg({ ao: 0, msaa: 4, ... })` 画質の設定を一時的に上書き（`ROOM.cfg(null)` で戻す）
  - `ROOM.bench(20)` 続けて描いて、1フレームあたりの時間（ミリ秒）を返す
  - `ROOM.poison(1)` 画面の1点に不正な値（NaN）を置く。黒い四角に広がらないことの確認用（`ROOM.poison(0)` で戻す）
- URL の末尾に `#nobox` を付けると、映りこみの位置補正なしで起動します（比較用）。
